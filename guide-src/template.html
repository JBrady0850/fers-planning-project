FERS Planning
Project

An evidence backed retirement planning system
for United States federal employees

A project prompt, a fourteen block interview, seventeen report specifications, an entry engine, and a validation loop that checks your planning software against your own documents. Built to run in Claude Desktop against a folder on your computer.
